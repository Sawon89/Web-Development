# Day 5 — Responsive Design (Media Queries)
## 📖 Study Material

---

## 1. Responsive Design কী?
বর্তমানে মানুষ ওয়েবসাইট শুধু কম্পিউটারে দেখে না, মোবাইল বা ট্যাবেও দেখে। একটা ওয়েবসাইট যেন ল্যাপটপ, ট্যাবলেট এবং মোবাইল—সব ডিভাইসেই সুন্দর দেখায়, সেই পদ্ধতিকেই **Responsive Design** বলে। 

গতকাল আমরা Grid এর `auto-fit` দিয়ে কিছুটা রেসপন্সিভ করা শিখেছি। আজ শিখব CSS এর সবচেয়ে শক্তিশালী অস্ত্র: **Media Queries**।

---

## 2. Media Queries কী?
Media Query হলো এমন একটা শর্ত (Condition), যা বলে দেয়: *"স্ক্রিন যদি এতো ছোট বা এতো বড় হয়, তাহলে CSS কোডগুলো এমনভাবে কাজ করবে।"*

```css
/* সাধারণ কোড (যা ল্যাপটপ বা বড় স্ক্রিনে কাজ করবে) */
body {
    background-color: lightblue;
}

/* Media Query: যদি স্ক্রিন ৬০০ পিক্সেল বা তার চেয়ে ছোট হয় (মোবাইল) */
@media (max-width: 600px) {
    body {
        background-color: lightcoral;
    }
}
```
*ব্যাখ্যা: উপরের কোডে বড় স্ক্রিনে ব্যাকগ্রাউন্ড হালকা নীল থাকবে, কিন্তু কেউ যদি ফোন দিয়ে সাইট ওপেন করে (স্ক্রিন ৬০০px এর কম), তখন ব্যাকগ্রাউন্ড হালকা লাল হয়ে যাবে!*

---

## 3. Mobile-First Approach (আধুনিক নিয়ম)
সবচেয়ে ভালো প্র্যাকটিস হলো আগে মোবাইলের জন্য ডিজাইন করা, এরপর বড় স্ক্রিনের জন্য Media Query লেখা।

```css
/* ১. প্রথমে মোবাইলের জন্য সাধারণ কোড */
.card-container {
    display: flex;
    flex-direction: column; /* মোবাইলে কার্ডগুলো নিচে নিচে থাকবে */
}

/* ২. ল্যাপটপ/পিসির জন্য Media Query (min-width) */
@media (min-width: 768px) {
    .card-container {
        flex-direction: row; /* স্ক্রিন ৭৬৮px এর বড় হলে কার্ডগুলো পাশাপাশি চলে আসবে */
    }
}
```

---

## 4. Breakpoints (কোথায় ভাঙব?)
স্ট্যান্ডার্ড কিছু স্ক্রিন সাইজ আছে, যেখানে ডিজাইন পরিবর্তন করতে হয়। এগুলোকে ব্রেকপয়েন্ট বলে:
- **Mobile (মোবাইল):** `320px` থেকে `480px`
- **Tablet (ট্যাব):** `768px` এর আশেপাশে
- **Desktop (পিসি):** `1024px` এবং তার বেশি

```css
/* ট্যাবলেট এর জন্য */
@media (max-width: 768px) {
    /* কোড এখানে */
}

/* মোবাইল এর জন্য */
@media (max-width: 480px) {
    /* কোড এখানে */
}
```

---

## 5. রেসপন্সিভ করার অন্যান্য টিপস
1. **ছবির সাইজ:** ছবি যেন কখনো তার কন্টেইনারের চেয়ে বড় না হয়ে যায়। 
   ```css
   img {
       max-width: 100%;
       height: auto;
   }
   ```
2. **Width এ `%` ব্যবহার করা:** নির্দিষ্ট পিক্সেল (যেমন `width: 500px;`) না দিয়ে `width: 100%;` বা `width: 50%;` দেওয়া ভালো।

---

## 6. আজকের Summary

✅ **Responsive Design** ওয়েবসাইটকে সব ডিভাইসে সুন্দর করে তোলে।  
✅ **Media Queries (`@media`)** দিয়ে স্ক্রিনের সাইজ অনুযায়ী আলাদা CSS লেখা যায়।  
✅ **`max-width`** মানে "এত পিক্সেল পর্যন্ত"।  
✅ **`min-width`** মানে "এত পিক্সেল থেকে শুরু করে বড় সব স্ক্রিনে"।  
✅ ছবিতে সবসময় `max-width: 100%;` ব্যবহার করা ভালো।
