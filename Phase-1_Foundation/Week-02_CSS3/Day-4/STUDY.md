# Day 4 — CSS Grid (2D Layout)
## 📖 Study Material

---

## 1. CSS Grid কী?
গতকাল আমরা Flexbox শিখেছি, যা 1-Dimensional (একমাত্রিক) অর্থাৎ শুধু Row বা শুধু Column নিয়ে কাজ করে। 
কিন্তু **CSS Grid** হলো **2-Dimensional (দ্বিমাত্রিক)**। এটা দিয়ে একই সাথে Row (সারি) এবং Column (কলাম) নিয়ন্ত্রণ করা যায়। একটা পুরো পেজের লেআউট বা বড় গ্যালারি তৈরি করতে Grid এর কোনো তুলনা নেই।

---

## 2. Grid-এর বেসিক ধারণা
Flexbox-এর মতোই Grid ব্যবহার করতে হলে Parent Element কে "Grid Container" বানাতে হবে।

```css
/* Container কে Grid বানানোর কোড */
.container {
    display: grid;
}
```

---

## 3. Columns এবং Rows তৈরি করা (Grid Template)

Grid-এ তোমাকে বলে দিতে হবে তুমি কয়টা কলাম বা রো চাও এবং তাদের সাইজ কেমন হবে।
এখানে `fr` (Fractional Unit) নামে একটা দারুণ জিনিস আছে। `1fr` মানে হলো স্ক্রিনের বাকি জায়গার ১ ভাগ।

```css
.container {
    display: grid;
    
    /* কলাম তৈরি: 3 টা কলাম হবে, প্রত্যেকটা সমান (1fr) সাইজের */
    grid-template-columns: 1fr 1fr 1fr; 
    
    /* বা শর্টকাট (Repeat): 3 টা কলাম, 1fr করে */
    grid-template-columns: repeat(3, 1fr);
    
    /* রো (Row) এর উচ্চতা: 2 টা রো, প্রত্যেকটা 100px উচু */
    grid-template-rows: 100px 100px;
}
```

---

## 4. Gap (ফাঁকা জায়গা)
আইটেমগুলোর মাঝখানে ফাঁকা জায়গা দেওয়ার জন্য Flexbox-এর মতোই `gap` ব্যবহার করা হয়।

```css
.container {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 20px; /* উপরে-নিচে এবং ডানে-বামে 20px ফাঁকা */
}
```

---

## 5. আইটেমগুলোকে ছড়ানো (Spanning)
ধরো, তোমার ৩টা কলাম আছে, কিন্তু তুমি চাও প্রথম আইটেমটা ২টা কলামের জায়গা নিয়ে নিক। তখন `grid-column` ব্যবহার করতে হয়।

```css
.item-1 {
    /* প্রথম লাইন থেকে শুরু করে ৩ নম্বর লাইন পর্যন্ত ছড়াবে (অর্থাৎ ২টা কলাম নিবে) */
    grid-column: 1 / 3; 
}
```
*(নোট: Grid-এ কলামের দাগ বা লাইন গোণা হয়, বক্স নয়। ৩টা কলাম হলে ৪টা লাইন থাকে!)*

---

## 6. Auto-fit এবং Minmax (জাদুকরী রেসপন্সিভ গ্রিড!)
স্ক্রিন ছোট হলে আইটেমগুলো নিজে থেকেই যেন নিচে নেমে যায়, তার জন্য এই ম্যাজিক কোডটি মুখস্থ করে ফেলো:

```css
.gallery {
    display: grid;
    /* এটা স্ক্রিন অনুযায়ী নিজে থেকেই কলামের সংখ্যা ঠিক করবে! */
    grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
    gap: 20px;
}
```
*ব্যাখ্যা: ஒவ்வொரு কলাম কমপক্ষে `200px` হবে, আর জায়গা থাকলে `1fr` (বড়) হবে। স্ক্রিন ছোট হয়ে ২০০px এর কম জায়গা থাকলে, ওটা নিচে নেমে যাবে।*

---

## 7. Flexbox বনাম Grid (কখন কোনটা ব্যবহার করবে?)
- **Flexbox:** যখন আইটেমগুলোকে শুধু এক লাইনে (পাশাপাশি বা নিচে নিচে) সাজাতে চাও। (যেমন: নেভিগেশন বার, ছোট কার্ডের লিস্ট)।
- **Grid:** যখন পুরো পেজের লেআউট বা বড় কোনো গ্যালারি বানাতে চাও, যেখানে একই সাথে রো এবং কলাম মেইনটেইন করতে হবে। (যেমন: ফটো গ্যালারি, ড্যাশবোর্ড)।

---

## 8. আজকের Summary

✅ **`display: grid;`** দিয়ে Grid चालू করতে হয়।  
✅ **`grid-template-columns`** দিয়ে কয়টা কলাম হবে তা ঠিক করতে হয়।  
✅ **`fr`** (Fraction) ইউনিট ব্যবহার করে কলামগুলোকে সমান ভাগে ভাগ করা যায়।  
✅ **`repeat(auto-fit, minmax(...))`** হলো রেসপন্সিভ গ্যালারি বানানোর ম্যাজিক।
