## 1. Function কী এবং কেন লাগে?
ধরে নাও, তুমি একটা কোড লিখেছ যেটা দুটো সংখ্যা যোগ করতে পারে। এখন প্রোগ্রামের ৫ জায়গায় তোমার ওই একই যোগ করার লজিকটা লাগবে। তুমি কি ৫ বার একই কোড কপি-পেস্ট করবে? না! 
আমরা ওই কোডটাকে একটা **বাক্সে** ভরে একটা **নাম** দিয়ে দেব। তারপর যখনই দরকার হবে, ওই নাম ধরে ডাকলেই বাক্সটার ভেতরের কোড রান করবে। এই বাক্সটাকেই প্রোগ্রামিংয়ের ভাষায় বলা হয় **Function**।

Python এ ফাংশন বানাতে `def` কিওয়ার্ড ব্যবহার করা হয় (def মানে define)।

---

## 2. ফাংশন তৈরি করা (Define) এবং ডাকা (Call)

### 2.1 সাধারণ ফাংশন
```python
# ফাংশন তৈরি করা (Defining)
def greet():
    print("Hello! Welcome to Software Engineering.")
    print("Have a nice day!")

# ফাংশন ডাকা (Calling) - না ডাকলে ফাংশন রান করবে না!
greet()
greet()  # দুইবার ডাকলাম, দুইবার প্রিন্ট হবে
```

## 3. Parameters এবং Arguments (ফাংশনের ভেতরে ডেটা পাঠানো)
আমরা চাইলে ফাংশনের ভেতরে বাইরে থেকে ভ্যালু বা ডেটা পাঠিয়ে দিতে পারি। এগুলোকে Parameter বলে।

```python
# 'name' হলো Parameter
def say_hello(name):
    print(f"Hello {name}! How are you?")

# "Sawon" হলো Argument (যেই ভ্যালুটা পাস করছি)
say_hello("Sawon")
say_hello("Alex")
```

একাধিক Parameter ও পাঠানো যায়:
```python
def add_numbers(a, b):
    result = a + b
    print(f"The sum of {a} and {b} is: {result}")

add_numbers(10, 5)   # 15 প্রিন্ট হবে
add_numbers(50, 20)  # 70 প্রিন্ট হবে
```

## 4. Return Value (ফাংশন থেকে ফলাফল ফেরত নেওয়া)
কখনো কখনো আমরা চাই না ফাংশন নিজেই কিছু `print` করুক। আমরা চাই সে হিসাব করে ফলাফলটা আমাদের কাছে **ফেরত (return)** দিক, যাতে আমরা সেটা অন্য কোনো কাজে ব্যবহার করতে পারি।

```python
def multiply(x, y):
    result = x * y
    return result  # ফলাফলটা ফেরত পাঠাচ্ছে

# ফাংশন কল করে রিটার্ন ভ্যালুটা একটা ভেরিয়েবলে সেভ করলাম
total = multiply(4, 5)

print(f"Total is: {total}") # এখন আমি চাইলে এটাকে প্রিন্ট করতে পারি
print(f"Double of total is: {total * 2}") # অথবা এটা নিয়ে অন্য হিসাবও করতে পারি!
```

> **⚠️ মনে রাখবে:** `return` লেখার পর ফাংশন ওখানেই থেমে যায়। `return` এর নিচে ওই ফাংশনের ভেতরে আর কোনো কোড লিখলে সেটা রান হয় না।

## 5. Default Parameters (ডিফল্ট ভ্যালু)
তুমি চাইলে প্যারামিটারের একটা ডিফল্ট ভ্যালু দিয়ে রাখতে পারো। যদি ফাংশন ডাকার সময় কেউ ভ্যালু না দেয়, তাহলে ডিফল্ট ভ্যালুটা ব্যবহার হবে।

```python
def order_coffee(size="Medium"):
    print(f"You ordered a {size} coffee.")

order_coffee("Large")  # প্রিন্ট করবে: Large
order_coffee()         # ভ্যালু দেইনি, তাই প্রিন্ট করবে: Medium (Default)
```

## 6. আজকের মূল বিষয়গুলো (Summary)
✅ **def**: ফাংশন তৈরি করার জন্য।  
✅ **Calling**: ফাংশনের নাম লিখে ব্র্যাকেট `()` দিলে ফাংশন রান করে।  
✅ **Parameters**: ফাংশনের ভেতরে ভ্যালু পাঠানোর রাস্তা।  
✅ **Return**: ফাংশন থেকে হিসাব করা ডেটা ফেরত নেওয়ার উপায়।  
✅ **Default Value**: প্যারামিটারে আগে থেকেই মান সেট করে রাখা।
