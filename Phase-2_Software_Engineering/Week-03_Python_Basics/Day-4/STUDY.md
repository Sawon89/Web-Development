## 1. Loop কী এবং কেন লাগে?
ধরে নাও, তোমাকে বলা হলো তোমার নাম ১০ বার প্রিন্ট করতে। তুমি হয়তো ১০ বার `print("Sawon")` লিখবে। কিন্তু যদি বলা হয় ১০০০ বার লিখতে? তখন কি ১০০০ বার লিখবে? না! 
এই ধরনের বারবার একই কাজ (Repetitive tasks) সহজে করার জন্যই **Loop** ব্যবহার করা হয়।

Python এ মূলত ২ ধরনের Loop আছে:
1. `for` loop
2. `while` loop

---

## 2. 'for' Loop
যখন আমরা আগে থেকেই জানি যে কতবার লুপ ঘুরাতে হবে, তখন `for` loop ব্যবহার করা হয়। `range()` ফাংশনের সাথে `for` লুপ খুব বেশি ব্যবহৃত হয়।

### 2.1 range() ফাংশন
```python
# 0 থেকে 4 পর্যন্ত প্রিন্ট করবে (5 এর আগ পর্যন্ত)
for i in range(5):
    print(i)
```

```python
# 1 থেকে 5 পর্যন্ত প্রিন্ট করবে
for i in range(1, 6):
    print(i)
```

```python
# 2 করে গ্যাপ দিয়ে 1 থেকে 10 এর মধ্যে সংখ্যা প্রিন্ট করবে (1, 3, 5, 7, 9)
for i in range(1, 10, 2):
    print(i)
```

### 2.2 String এর মধ্যে for Loop
```python
name = "Python"
for letter in name:
    print(letter)
```
*Output: P, y, t, h, o, n আলাদা লাইনে প্রিন্ট হবে।*

## 3. 'while' Loop
যখন আমরা জানি না কতবার লুপ ঘুরবে, কিন্তু একটা **শর্ত (condition)** এর ওপর নির্ভর করে লুপ চালাতে চাই, তখন `while` loop ব্যবহার করা হয়। শর্তটি যতক্ষন `True` থাকবে, লুপ ঘুরতেই থাকবে।

```python
count = 1

while count <= 5:
    print("গাড়ির চাকা ঘুরছে:", count)
    count += 1  # count এর মান 1 বাড়িয়ে দিলাম, না হলে লুপ সারাজীবন চলতেই থাকবে! (Infinite Loop)
```

## 4. Break এবং Continue

লুপের স্বাভাবিক নিয়ম ভাঙার জন্য এই দুটো জিনিস ব্যবহৃত হয়।

### 4.1 break (লুপ থেকে বের হয়ে যাও)
লুপ মাঝপথে থামিয়ে দেওয়ার জন্য `break` ব্যবহার করা হয়।
```python
for i in range(1, 10):
    if i == 5:
        break  # i এর মান 5 হলেই লুপ পুরোপুরি থেমে যাবে
    print(i)
```
*Output: 1, 2, 3, 4*

### 4.2 continue (এই ধাপটা বাদ দিয়ে পরের ধাপে যাও)
```python
for i in range(1, 6):
    if i == 3:
        continue  # i এর মান 3 হলে এই ধাপ স্কিপ করে পরের ধাপে যাবে
    print(i)
```
*Output: 1, 2, 4, 5 (3 প্রিন্ট হয়নি!)*

## 5. Infinite Loop (লুপের বিপদ!)
লুপে শর্ত যদি সবসময় সত্যি থাকে এবং কখনো মিথ্যা না হয়, তাহলে লুপ চলতেই থাকবে, কম্পিউটার হ্যাং করতে পারে!
```python
# ⚠️ এই কোডটি রান কোরো না!
# while True:
#     print("আমি থামব না!")
```

## 6. আজকের মূল বিষয়গুলো (Summary)
✅ **for loop**: নির্দিষ্ট সংখ্যক বার কাজ করার জন্য।  
✅ **while loop**: শর্ত পূরণ না হওয়া পর্যন্ত কাজ করার জন্য।  
✅ **range(start, stop, step)**: সংখ্যার সিকোয়েন্স তৈরি করার জন্য।  
✅ **break**: লুপ সম্পূর্ণভাবে থামানোর জন্য।  
✅ **continue**: লুপের শুধু বর্তমান ধাপটি বাদ দিয়ে পরবর্তী ধাপে যাওয়ার জন্য।
