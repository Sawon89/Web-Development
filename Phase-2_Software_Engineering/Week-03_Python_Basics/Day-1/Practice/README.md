# 📝 Day 1 — Practice Area
## তোমার কাজের জায়গা

---

## এই folder এ কী করবে?

এই `Practice` folder টা শুধু **তোমার জন্য** — এখানে তুমি lab এর tasks করবে।

---

## কীভাবে কাজ করবে?

1. **`my_work.py`** file টা VS Code এ খোলো
2. **`../LAB.md`** দেখে একটা একটা করে task করো
3. প্রতিটা task এর পর `python my_work.py` run করো
4. কাজ শেষে **আমাকে বলো** — "আমি Week 3 - Day 1 lab শেষ করেছি, check করো"
5. আমি তোমার `my_work.py` **check করব**
6. সব ঠিক থাকলে → Day 2 পাবে ✅

---

## ⚠️ Rules

- Placeholder গুলো (`[তোমার নাম]`) **নিজের তথ্য দিয়ে** replace করো
- LAB.md এর **সব task** করতে হবে
- কোনো সমস্যা হলে আমাকে **জিজ্ঞেস করো** — এগিয়ে যাওয়ার আগে বোঝো
- **Copy-paste করো না** — নিজে টাইপ করো, তাহলে মনে থাকবে!
