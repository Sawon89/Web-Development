# Day 3 — Conditionals (if / elif / else)
## 📖 Study Material

---

## 1. Conditionals (শর্ত) কী?
বাস্তব জীবনে আমরা অনেক সিদ্ধান্ত নিই শর্তের ওপর ভিত্তি করে। যেমন: "যদি বৃষ্টি হয়, তাহলে ছাতা নেব, না হলে নেব না।"
প্রোগ্রামিংয়ে এই "যদি (if)" এবং "না হলে (else)" এর লজিককেই বলে **Conditionals**।

Python এ Conditionals এর জন্য ৩টি প্রধান কিওয়ার্ড ব্যবহার করা হয়:
1. `if` (যদি)
2. `elif` (অথবা যদি)
3. `else` (না হলে)

---

## 2. If Statement (শুধুমাত্র 'যদি')
```python
age = 20

# if এর পর condition দিতে হয়, শেষে কোলন (:) দিতে হয়।
# কোলনের পর যে লাইনগুলো থাকে, সেগুলোর আগে ৪টা space (Indentation) দিতে হয়।
if age >= 18:
    print("তুমি প্রাপ্তবয়স্ক!")
    print("তুমি ভোট দিতে পারবে।")

# এই লাইনটা if এর বাইরে, তাই এটা সবসময় প্রিন্ট হবে।
print("প্রোগ্রাম শেষ।")
```
> **⚠️ Indentation (ফাঁকা জায়গা) Warning:** Python এ space বা indentation খুবই জরুরি। `if` এর ভেতরে যা থাকবে, তা সবসময় একটু ডানে সরিয়ে লিখতে হবে (Tab বা 4 spaces দিয়ে)।

---

## 3. If - Else (যদি - না হলে)
যখন দুটো অপশন থাকে: হয় এটা, না হয় ওটা।

```python
temperature = 25

if temperature > 30:
    print("আজ অনেক গরম!")
else:
    print("আজ আবহাওয়া ভালো।")
```

---

## 4. If - Elif - Else (একাধিক শর্ত)
যখন আমাদের কাছে অনেকগুলো অপশন থাকে। (যেমন: Grade বের করা)

```python
marks = 75

if marks >= 80:
    print("তুমি A+ পেয়েছ!")
elif marks >= 70:
    print("তুমি A পেয়েছ!")
elif marks >= 60:
    print("তুমি A- পেয়েছ!")
else:
    print("তোমাকে আরও ভালো করতে হবে।")
```
এখানে Python উপর থেকে চেক করতে করতে আসবে। যে শর্তটি প্রথম সত্যি হবে, শুধু সেটার ভেতরের কোডই রান করবে। বাকিগুলো আর চেক করবে না।

---

## 5. Nested If (শর্তের ভেতরে শর্ত)
কখনো কখনো একটি শর্ত সত্যি হওয়ার পর আরও কিছু চেক করতে হয়।

```python
has_ticket = True
age = 15

if has_ticket:
    print("টিকিট আছে।")
    
    # Nested if
    if age < 18:
        print("বাচ্চাদের সিটে বসো।")
    else:
        print("বড়দের সিটে বসো।")
else:
    print("তুমি ঢুকতে পারবে না।")
```

## 6. Logical Operators এর ব্যবহার (and, or, not)
Day 2 তে আমরা যেগুলো শিখেছিলাম, সেগুলো if এর সাথে খুব দারুণভাবে ব্যবহার করা যায়।

```python
income = 50000
has_good_credit = True

# দুটোই সত্যি হতে হবে
if income > 40000 and has_good_credit:
    print("তুমি লোন পাবে!")
else:
    print("তুমি লোন পাবে না।")
```

---

## 7. আজকের মূল বিষয়গুলো (Summary)
✅ **if**: প্রথম শর্ত চেক করে।  
✅ **elif**: আগের শর্ত মিথ্যা হলে, নতুন শর্ত চেক করে।  
✅ **else**: উপরের কোনো শর্ত সত্যি না হলে এটা রান হয়।  
✅ **Indentation**: ব্লক (block) বোঝাতে tab/4 spaces দিতে হয়।  
✅ **Nested if**: এক if এর ভেতরে আরেক if।
